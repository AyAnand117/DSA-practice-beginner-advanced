# DSA Practice (Beginner → Advanced)

A running notebook of my Data Structures & Algorithms practice in Python — starting from number-theory basics and building up over time.

## What's inside

`DSA Practice.ipynb` currently covers:

- **Digit Extraction** — pulling digits from a number one at a time using `% 10` and `// 10`
- **Counting Digits** — three approaches: manual loop, list-based, and `log10` formula
- **Palindrome Number Check** — reversing a number and comparing to the original
- **Armstrong Number Check** — two implementations, comparing list-based vs. accumulator-based approaches

Each solution includes time/space complexity notes (e.g. `O(log₁₀ n)` for digit-based operations).

## Why this repo

Practicing core DSA patterns in Python as part of interview prep — moving from brute-force to optimized solutions, and comparing multiple approaches to the same problem.
